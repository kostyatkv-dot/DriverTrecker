# Робочий час — Android-додаток

Облік робочого часу на заводі: зміни, години за тиждень/місяць, зарплата за тарифом
і понаднормові (за замовчуванням: понад 7 год на день, +25%). Експорт звітів в Excel.

## Можливості
- Таймер «Почати / Завершити зміну» (працює навіть якщо закрити додаток).
- Ручне додавання та редагування змін (дата, початок, кінець, перерва, ставка, примітка).
- Кілька ставок (напр. основна, нічна, вихідний) — обирається для кожної зміни.
- Понаднормові рахуються за кожен день; поріг і надбавка налаштовуються.
- Підсумки: сьогодні, тиждень, місяць; звіт по днях і по ставках; сума брутто.
- Експорт тижня або місяця у файл Excel (.xlsx).
- Дані зберігаються лише на телефоні.

## Встановлення на телефон
1. Відкрийте на телефоні сторінку **Releases** цього репозиторію → «Робочий час — остання збірка».
2. Завантажте `WorkTime.apk` і відкрийте його.
3. Дозвольте встановлення з цього джерела, якщо Android попросить.

Нові версії встановлюються поверх старої — дані зберігаються.

## Збирання
APK збирається автоматично GitHub Actions (`.github/workflows/build-apk.yml`) при кожному push.
Локально: `./gradlew assembleRelease` (потрібен Android SDK).

Технології: Kotlin, Jetpack Compose (Material 3), minSdk 26, targetSdk 35.
